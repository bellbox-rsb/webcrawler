# Web Crawler & Document Viewer

A modern web crawler and documentation viewer built with **Vue 3** and **Vite**.

## Features

- **Web Crawler**: Crawl websites and extract content, technology stack, and media.
- **Neural Search Interface**: Clean, noise-free search experience.
- **Rich Text Editor**: Integrated Tiptap editor for viewing and editing crawled content.
- **Markdown Viewer**: Render local documentation files with GitHub-style formatting.
- **Dark Mode**: sleek, deep mode UI.

## Tech Stack

- **Framework**: Vue 3 (Composition API)
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Routing**: Vue Router
- **Icons**: Lucide Vue Next
- **Editor**: Tiptap Vue 3
- **HTTP Client**: Axios

## Getting Started

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Start Development Server**
   ```bash
   npm run dev
   ```

3. **Build for Production**
   ```bash
   npm run build
   ```
