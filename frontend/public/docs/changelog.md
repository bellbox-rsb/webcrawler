# Changelog

All notable changes to the WebCrawler project.

## [v3.0.0] - 2025-12-30
### Major Release
-   **Architecture**: Decoupled Frontend (React) and Backend (Flask).
-   **UI**: Complete rewrite using **Vite + React**.
-   **Editor**: Replaced QuillJS with **Tiptap** for a premium "Ghost-style" editing experience.
-   **Infrastructure**: Fully Dockerized with `docker-compose` and easy start scripts.
-   **Design**: Implemented "Nexus" design system (Dark Mode, Deep Mode Toggle, Feature Grid).
-   **Fixes**: Resolved PostCSS/Tailwind configuration issues for reliable styling.

## [v2.1.1] - 2025-12-28
### Fixed
-   **Dependencies**: Added `setuptools`.

## [v2.1.0] - 2025-12-28
### Added
-   **Deployment**: Support for Vercel Serverless.

## [v2.0.0] - 2024-12-28
### Released
-   **New UI**: "Nexus" design system.
